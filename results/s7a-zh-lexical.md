日期：2026-11-10。花費 $0。這一段照交接文件可以在 N0 做完後先做，所以排在 S6 等待 GPU 的空檔完成。**S7b、S7c 沒有做**（S6 的結論是「改方向」）。

## 資料

- DRCD 官方發布版，`github.com/DRCKnowledgeTeam/DRCD` @ `b944790`。
- 語料：training、dev、test 三份的全部段落，共 10,014 段（只用 test 的段落太少，分不出斷詞方式的差別）。
- 題目：test 的 3,493 題，每題唯一的金標是它所在的段落。
- 簡體版：用 OpenCC `tw2sp` 把語料和題目都轉一份。
- 轉檔腳本 `tools/drcd_convert.py`、比較腳本 `tools/s7a_zh_lexical.py`；資料檔沒有進 git。
- 欄位權重用 `results/thresholds.lock.json` 的值（`title` 4，其餘 1）。

## 判定

**DRCD 分不出差別，維持預設的 `tw2sp` 加兩種欄位都開。**

- 九組正規化設定的 R@10 落在 97.05 到 97.71，相差 0.66 分，遠小於 2 分。
- 能看出來的只有兩件事：
  - 不做正規化、直接用 jieba 切繁體原文，R@10 低 1.7 分、R@1 低 5.5 分。jieba 預設詞典是簡體，切繁體比較差。
  - 有開 bigram 的組別 R@1 比只開 word 高約 3 分，R@10 只高 0.3 到 0.5 分。
- 正規化之後繁體版和簡體版幾乎逐題相同（差 0 到 0.09 分），符合「兩者相差 ≤ 2 分」。
- 這個測試有一個限制：簡體版是用 `tw2sp` 從繁體版轉出來的，問題和段落用的是同一套轉換，所以量不到「問題用台灣用語、文件用大陸用語」這種真正的跨地區落差。

## 轉換結果抽查

抽查用語料前 3,000 段，完整的例子在 `results/s7a-spotcheck.json`。

### 簡體鍵值：多對一合併

- 4,615 個相異的簡體字裡，有 165 個是由兩個以上的繁體字合併來的；這些字占全部字元出現次數的 9.3%。
- 出現次數最多的 30 組裡，會讓不同意思的詞變成同一個鍵值的例子：

| 簡體 | 合併前（出現次數） | 會誤配的情況 |
|---|---|---|
| 制 | 製 555、制 1,747 | 「製造」和「制度」的「制」變成同一個字 |
| 里 | 里 1,239、裡 360、裏 59 | 「公里」和「這裡」 |
| 系 | 系 1,054、係 335、繫 72 | 「系統」「關係」「聯繫」 |
| 历 | 歷 769、曆 184 | 「歷史」和「日曆」 |
| 复 | 復 494、複 181 | 「恢復」和「複雜」 |
| 干 | 幹 194、乾 138、干 122 | 「幹部」「乾燥」「干涉」 |
| 只 | 只 722、隻 92 | 「只有」和「一隻」 |
| 后 | 後 3,909、后 65 | 「之後」和「皇后」 |
| 面 | 面 1,742、麵 42 | 「方面」和「麵粉」 |
| 发 | 發 3,261、髮 34 | 「發現」和「頭髮」 |
| 征 | 徵 235、征 155 | 「特徵」和「征服」 |

- 這些合併只影響單字和跨詞邊界的 bigram。兩個字以上的詞（`cjk_word`）和詞內的 bigram 多半仍然不同（「頭髮」→「头发」、「發現」→「发现」）。從上面的 R@k 看不到可量測的損失。

### 繁體鍵值：一對多

把繁體原文用 `tw2sp` 轉成簡體，再用 `s2twp` 轉回繁體，和原文逐字比較：944,749 個中文字裡有 7,166 個不同（0.76%）。分成兩類：

- **字的寫法被換掉**（一對多時選了另一個字）：台→臺 599 次、布→佈 502 次、占→佔 392 次、里→裡 163 次、周→週 100 次、制→製 57 次。其中有真的轉錯的：「被當作『于』的異體」變成「於」、「張采田」（人名）變成「張採田」、「征榷」變成「徵榷」。
- **詞被換成台灣用語**（`twp` 的地區詞對應）：通過→透過 559 次、函數→函式、圖像→影象、視頻→影片、字體→字型、打開→開啟。其中有明顯的錯誤：「電視頻道」被切成「電／視頻／道」轉成「電影片道」。

這類錯誤在簡體鍵值不會發生（繁轉簡是多對一，不用猜）。這是維持簡體鍵值的主要理由；R@k 上兩者沒有差別。

## 結論

**繼續**（維持預設：鍵值用 `tw2sp`，`cjk_bigram` 和 `cjk_word` 兩個欄位都開）。DRCD 分不出各種設定的差別。
